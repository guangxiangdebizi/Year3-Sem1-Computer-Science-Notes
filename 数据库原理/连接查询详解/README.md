# 连接查询详解

本文件夹专门讲解SQL中的连接查询（JOIN），是数据库查询中最重要的内容之一。

## 📚 内容目录

1. **[内连接详解](内连接详解.md)** - INNER JOIN
   - 等值连接
   - 自然连接
   - 非等值连接

2. **[外连接详解](外连接详解.md)** - OUTER JOIN
   - 左外连接 (LEFT JOIN)
   - 右外连接 (RIGHT JOIN)
   - 全外连接 (FULL OUTER JOIN)
   - NULL值处理

   - 索引的使用
   - 实战案例分析

## 🎯 学习目标

- 掌握各种连接查询的语法和使用场景
- 理解连接查询的执行原理
- 能够根据实际需求选择合适的连接类型
- 掌握连接查询的性能优化方法

## 📖 推荐学习顺序

1. 先学习内连接，这是最基础和常用的连接方式
2. 再学习外连接，理解与内连接的区别
3. 掌握交叉连接和自连接的特殊用法
4. 最后学习优化技巧，提升查询效率
