## 🎨 改进的讲解风格

### 之前的风格：
```
"左外连接保留左表的所有记录，即使右表没有匹配的记录。"
```

### 现在的风格：
```
核心概念： 保留左表的所有记录，即使右表没有匹配的记录。

通俗理解： "以左表为主"，左表的每一行都要出现在结果中，右表没匹配的就填 NULL。

执行过程（逐步演示）：
第4步：取左表第4行（赵六 S004）  ← 关键！
  → 在右表 SC 中找 Sno = 'S004'
  → 找到0条！
  → 仍然生成1行结果，但 Cno 和 Grade 填充 NULL ⭐

执行结果：
| S004 | 赵六   | NULL | NULL  |  ← 赵六出现了！但选课信息是 NULL

关键观察：
- ✅ 赵六出现了！这就是左外连接的作用
```
